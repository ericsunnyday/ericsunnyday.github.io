Privacy Policy

YouTube Upload — a personal desktop publishing tool. Last updated: 1 October 2026.

This policy explains what Google user data YouTube Upload ("the tool") accesses, how that data is used and stored, and what is never done with it.

1. What Google user data is accessed

Scope requested What it allows
https://www.googleapis.com/auth/youtube.upload The ability to upload a video file to the authorizing channel and set that video's title, description, tags, category and privacy status.

That is the only permission the tool requests. It has no read access to channel analytics, subscriber data, comments, messages or any other Google service, and it cannot modify or delete content it did not upload.

2. How that data is used

Solely to perform the single action the operator asked for: publishing a video file that the operator already holds on their own computer to the operator's own YouTube channel. Nothing else is derived from the data.

3. How that data is stored

  • The OAuth credential (access token and refresh token) is written to a local file on the operator's own machine — ~/.config/youtube/token.json — with owner-only file permissions.
  • Video files and any metadata are stored on the operator's own machine.
  • No data is uploaded to any server controlled by the tool's author. There is no backend, no database and no telemetry.

4. Sharing with third parties

None. Google user data is never sold, rented, transferred or disclosed to any third party. No advertising, profiling or analytics service receives it.

5. Use of data for machine learning

Google user data is not used to develop, improve or train any machine-learning or artificial-intelligence model.

6. Retention and deletion

  • The local credential file is retained for as long as the operator keeps the tool installed, so that scheduled publishing can run without repeated sign-in.
  • The operator can revoke the tool's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored credential.
  • Deleting ~/.config/youtube/token.json removes the stored credential from the machine. Uninstalling the tool removes all remaining local data.

7. Limited Use disclosure

YouTube Upload's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to this policy

Any change to this policy will be published on this page with an updated date at the top. Because the tool serves a single operator, no notification mechanism beyond this page exists.
