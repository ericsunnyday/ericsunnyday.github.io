YouTube Upload

A personal desktop tool for publishing finished videos to their creator's own YouTube channel.

What this app does

YouTube Upload is a small, self-hosted command-line tool. It takes a video file that the operator has already produced and publishes it to the operator's own YouTube channel through the official YouTube Data API v3 — setting the title, description, tags, category and privacy status in the same request.

Who it is for

It is a single-user tool built for its own operator. It is not a public service, it has no sign-up, and it does not accept third-party users. Only the channel owner ever authorizes it, and it can only ever publish to the channel that granted it access.

How the authorization works

  • The tool requests exactly one permission: youtube.upload — the ability to upload a video and set its metadata.
  • It cannot read any other YouTube data, cannot modify or delete existing videos, and has no access to any other Google service.
  • Authorization happens once, in the operator's own browser, via Google's standard OAuth 2.0 consent flow.
  • The resulting credential is stored only on the operator's own computer and is never sent anywhere else.

What it does not do

  • It does not collect, aggregate or resell any data.
  • It does not access Google user data belonging to anyone other than its own operator.
  • It does not use Google user data for advertising, profiling, or training machine-learning models.
  • It does not transfer Google user data to any third party.
